## 2. 준비 원칙
- 암기형 스크립트보다 실제 경험 기반 답변을 우선한다.
- 질문별 답변보다 재사용 가능한 에피소드를 먼저 만든다.
- 답변은 “완성문 암기”가 아니라 “말할 순서” 중심으로 관리한다.
- 모든 답변은 가능하면 현재 설명 → 과거/현재 비교 → 구체 에피소드 → 감정/생각 → 마무리 구조로 확장한다.

## 3. 핵심 캐릭터
나는 어떤 사람으로 말할 것인가?

- 직업/일:
- 가족/생활:
- 자주 하는 활동:
- 최근 관심사:
- 나를 설명하는 키워드:

예시:
- IT 회사에서 일하는 직장인
- 가족과 시간을 중요하게 생각함
- 건강을 위해 러닝을 꾸준히 함
- 주말에는 아이들과 외출하거나 카페/공원에 감

## 4. 우선순위
1. 사전 서베이 확정
2. 한국어 원천 소스 정리
3. 핵심 에피소드 8~10개 확보
4. 답변 뼈대 생성
5. 영어 구어체 답변으로 변환
6. 녹음 피드백으로 수정

## 5. 답변 품질 기준
- 질문에 직접 답하는가?
- 구체적인 경험이 들어가는가?
- 과거/현재 비교 또는 변화가 있는가?
- 감정과 생각이 자연스럽게 들어가는가?
- 1분 30초 이상 말할 수 있는가?
- 외운 티가 나지 않는가?

## 6. 운영 방식
- 새 경험이 생기면 Source Pack에 먼저 추가한다.
- 답변을 만들면 Answer Bank에 저장한다.
- 말해보고 생긴 문제는 Feedback Log에 남긴다.
- 좋은 표현이나 에피소드는 Source Pack으로 다시 반영한다.
