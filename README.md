# OPIc AL 준비

OPIc AL 목표 준비를 위한 기준 문서 저장소입니다.

## 운영 원칙

- ChatGPT 프로젝트 대화방은 전략 수립, 소스 정리, 답변 제작, 실전 피드백 작업 공간으로 사용합니다.
- GitHub repo는 기준 문서의 원본 저장소로 사용합니다.
- 중요한 결정, 에피소드, 답변, 피드백은 `docs/` 하위 문서에 현행화합니다.

## 문서 구조

```txt
docs/
  01_OPIc_Strategy.md
  02_OPIc_Survey.md
  03_OPIc_Source_Pack.md
  04_OPIc_Answer_Bank.md
  05_OPIc_Feedback_Log.md

```

## 현재 우선순위

1. 사전 서베이 확정
2. 한국어 원천 소스 정리
3. 핵심 에피소드 8~10개 확보
4. 답변 뼈대 생성
5. 영어 구어체 답변 변환
6. 녹음 피드백으로 수정
